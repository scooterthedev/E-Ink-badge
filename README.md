# Inky - An E-Ink badge

This is an e-ink USB-C PCB badge that I'm building since I loved the Github one so much, and want to make my own! I decided that I wanted to follow a similar design route with the Github Badge so I went with the RP2040 IC.

This was my first time designing an FPC cable from scratch on a PCB! Originally, I wanted to do it to help make a board for my brother, but in the end, I found it too complicated. For this board, I decided to use Gemini to help me, since I wasn't able to find any good documentation of how to properly wire it up.

When I first started this, I though it would take at least 10 hours from when I glanced at the Github Badge, but in the end, it only took me about 4.3 hours which was insanely quick and efficient of my time!

I have attached some photos below outlining the PCB, Schematic and even the 3D rending's on the board!
